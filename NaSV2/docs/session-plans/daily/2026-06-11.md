P1 · `crates/presentation/src/app_state.rs` (NEW)

  ```rust
  //! Shared application state for the HTTP router.
  //!
  //! Cheap to clone (Arc internally). Cloned per request by axum's
  //! `with_state` mechanism.

  use std::sync::Arc;

  use nas2_application::ports::PostRepository;
  use nas2_tenant::TenantResolverHandle;

  #[derive(Clone)]
  pub struct AppState {
      pub post_repo: Arc<dyn PostRepository>,
      pub tenant_resolver: TenantResolverHandle,
  }

  impl AppState {
      #[must_use]
      pub fn new(
          post_repo: Arc<dyn PostRepository>,
          tenant_resolver: TenantResolverHandle,
      ) -> Self {
          Self { post_repo, tenant_resolver }
      }
  }
  ```

  Note: `AppState` deliberately stores `Arc<dyn ...>` not generic
  `<R: PostRepository>` — handlers need a single concrete state type
  to wire into axum. Use cases inside handlers stay generic and
  monomorphize over the Arc<dyn>.

P3 · `crates/presentation/src/router.rs` (NEW)

  ```rust
  //! Top-level axum router builder.
  //!
  //! Mount order:
  //!   1. routes (health endpoints today; /api/v1/pages tomorrow)
  //!   2. tenant_resolver middleware (LAST so it runs FIRST on
  //!      request — middleware order is request-from-outermost)
  //!   3. with_state(AppState)

  use axum::{middleware::from_fn_with_state, routing::get, Router};
  use nas2_tenant::resolve_tenant;

  use crate::app_state::AppState;
  use crate::health;

  /// Construct the full router. Apps wire this into `axum::serve`.
  #[must_use]
  pub fn build_router(state: AppState) -> Router {
      let resolver = state.tenant_resolver.clone();
      Router::new()
          .route("/health/live",  get(health::live))
          .route("/health/ready", get(health::ready))
          // tenant resolver runs before every request — except health
          // endpoints (mounted below the layer would still apply).
          // For now apply globally; carve out health later when
          // probe noise becomes a real concern.
          .layer(from_fn_with_state(resolver, resolve_tenant))
          .with_state(state)
  }
  ```

  Note: as written, `from_fn_with_state` makes `/health/*` *require*
  a valid Host header that's mapped. If that's a problem for the
  load balancer (which may probe without Host), refactor later via
  axum's `Router::nest` to scope the middleware. For W3 D4 the
  current shape is fine; document the trade-off.

              -> Result<nas2_common::Page<nas2_domain::Post>, nas2_common::AppError>;
          async fn insert(&self, _p: &nas2_domain::Post) -> Result<(), nas2_common::AppError>;
          async fn update(&self, _p: &nas2_domain::Post) -> Result<(), nas2_common::AppError>;
      }

  fn build_state_with_host(host: &str) -> AppState {
      let tid = TenantId::new_v4();
      let sid = SiteId::new_v4();
      let mut map = HashMap::new();
      map.insert(host.to_owned(), TenantContext::new(tid, sid));
      let resolver = Arc::new(InMemoryTenantResolver::new(map));
      AppState::new(Arc::new(MockRepo::new()), resolver)

          .header(header::HOST, "example.com")

      assert_eq!(resp.status(), StatusCode::NOT_FOUND);
  }

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **Cross-crate `mockall::automock`-generated types are NOT
     exported across crate boundaries.** The application crate's
     `MockPostRepository` is `#[cfg(test)]`-only and visible only
     within its own test target. For presentation's tests we declare
     a local `mock!`-based MockRepo. Same applies to other
     integration test files.
  2. **`Router<AppState>` type parameter.** Adding `with_state(state)`
     erases the type parameter into `Router<()>`. The test code calls
     `Router::with_state(state)` at construction; `app: Router` after
     that.
  3. **Middleware order.** `Router::layer(X).layer(Y)` runs Y first
     on request (outermost-first). We have only one middleware today
     so this doesn't bite; keep in mind for W3 D5.
  4. **The `/health/live` middleware coupling.** A platform probe
     hitting `/health/live` from a private NLB without setting Host
     properly will get 400. If you see flapping probes in prod, that's
     the cause — fix by nesting health routes outside the resolver.
  5. **`Arc<dyn PostRepository>` requires the trait be dyn-safe.**
     Verified W2 D5 — `_assert_object_safe`.
