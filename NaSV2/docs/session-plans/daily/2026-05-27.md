COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **CI log files are gitignored.** The `tee` outputs land under
     `docs/session-logs/` which the repo `.gitignore` excludes — they
     stay on the local machine. Reference them by path in SESSION_LOG
     but do NOT try to commit them (the bootstrap forbade
     `git add -f`).
  2. **`magic-check` false positive on `tokio::main` macro.** The macro
     expands to `tokio::runtime::Builder::...`; our regex matches
     `\btokio::spawn\(` only — `tokio::main` is safe. If a future
     macro is added that internally uses `tokio::spawn`, file the
     finding in SESSION_LOG and add a path whitelist comment in
     `magic_check.rs`.
  3. **`check-planning-refs --commit HEAD`** — *single* commit. Range
     specs (`A..B`) also work and are what CI should use.
  4. **Don't edit the parent repo's `.github/workflows/`.** Period.
