# VAL-005 — RLS isolation property test

## Status
Accepted · 2026-06-26.

## Claim being verified
**For any two distinct tenants A ≠ B, no operation performed as
`ax_app` with `app.tenant_id = A` can produce a row visible to a
subsequent operation with `app.tenant_id = B` — and conversely no
INSERT under A can land tenant_id = B.**

## Method
Property test using `proptest` (workspace dep). 1000 rounds, each:
  1. Generate random `(tenant_a, tenant_b)` pair (a ≠ b)
  2. Generate random sites + posts + users + roles + assignments
     under tenant A
  3. Switch GUC to tenant B
  4. Assert all SELECT counts = 0
  5. Attempt INSERT with explicit tenant_id = A while GUC = B
  6. Assert all attempts fail with RLS-policy violation

## Tables covered
  - sites, posts (0003 policies)
  - users, roles, role_capabilities, user_role_assignments
    (0007 policies)

## Failure mode if test ever fails
Stop using the schema until the bypass is closed. The test is the
canonical evidence of §15 isolation; a passing test is what allows
all downstream repository code to assume tenant isolation.

## References
- ADR-010 RLS policy shape
- ENTITY §3.3, §15
- migrations/0003_rls_sites_posts.sql
- migrations/0007_rls_users_roles.sql

//! Property-based RLS isolation verifier · VAL-005.
//!
//! Runs only under #[ignore] + `--ignored` because it spins up
//! testcontainers Postgres + applies all migrations + does 1000
//! proptest rounds.

#![cfg(test)]
#![allow(clippy::expect_used, clippy::unwrap_used, clippy::panic)]

use proptest::prelude::*;
use sqlx::postgres::PgPoolOptions;
use std::time::Duration;
use testcontainers::runners::AsyncRunner;
use testcontainers_modules::postgres::Postgres;
use uuid::Uuid;

const ROUNDS: u32 = 1000;

#[tokio::test]
#[ignore = "needs Docker — long-running (1000 proptest rounds)"]
async fn rls_isolation_1000_rounds() {
    let pg = Postgres::default()
        .with_user("postgres").with_password("postgres").with_db_name("ax")
        .start().await.unwrap();
    let port = pg.get_host_port_ipv4(5432).await.unwrap();
    let url = format!("postgres://postgres:postgres@127.0.0.1:{port}/ax");
    let pool = PgPoolOptions::new()
        .max_connections(8)
        .acquire_timeout(Duration::from_secs(10))
        .connect(&url).await.unwrap();

    // Apply 0002..0007 in sequence (skip 0001 pgmq — not in test image).
    for n in 2..=7 {
        let path = format!("../../migrations/{n:04}_*.sql");
        let entries: Vec<_> = glob::glob(&path).unwrap().filter_map(Result::ok).collect();
        for p in entries {
            let sql = std::fs::read_to_string(&p).unwrap();
            sqlx::query(&sql).execute(&pool).await
                .unwrap_or_else(|e| panic!("migration {p:?} failed: {e}"));
        }
    }

    // Property: tenant B cannot see / write to tenant A's rows.
    let strategy = (uuid_strat(), uuid_strat())
        .prop_filter("tenants must differ", |(a, b)| a != b);

    let mut runner = proptest::test_runner::TestRunner::deterministic();
    for round in 0..ROUNDS {
        let case = strategy.new_tree(&mut runner).unwrap();
        let (tenant_a, tenant_b) = case.current();
        run_one_round(&pool, tenant_a, tenant_b, round).await;
    }
}

fn uuid_strat() -> impl proptest::strategy::Strategy<Value = Uuid> {
    proptest::array::uniform16(any::<u8>())
        .prop_map(Uuid::from_bytes)
}

async fn run_one_round(pool: &sqlx::PgPool, ta: Uuid, tb: Uuid, round: u32) {
    // === Phase 1: insert under tenant A ===
    let mut tx = pool.begin().await.unwrap();
    sqlx::query("SET LOCAL ROLE ax_app").execute(&mut *tx).await.unwrap();
    sqlx::query("SELECT set_config('app.tenant_id', $1, true)")
        .bind(ta.to_string()).execute(&mut *tx).await.unwrap();

    let site_id = Uuid::new_v4();
    let slug = format!("s{round}");
    sqlx::query(
        "INSERT INTO sites (id, tenant_id, slug, display_name) \
         VALUES ($1, $2, $3, 'A')"
    ).bind(site_id).bind(ta).bind(&slug).execute(&mut *tx).await.unwrap();

    sqlx::query(
        "INSERT INTO posts (id, site_id, tenant_id, slug, title, status, blocks) \
         VALUES ($1, $2, $3, $4, 'T', 'published', '[]'::jsonb)"
    ).bind(Uuid::new_v4()).bind(site_id).bind(ta).bind(&slug)
     .execute(&mut *tx).await.unwrap();

    tx.commit().await.unwrap();

    // === Phase 2: switch to tenant B, assert ZERO visibility ===
    let mut tx2 = pool.begin().await.unwrap();
    sqlx::query("SET LOCAL ROLE ax_app").execute(&mut *tx2).await.unwrap();
    sqlx::query("SELECT set_config('app.tenant_id', $1, true)")
        .bind(tb.to_string()).execute(&mut *tx2).await.unwrap();

    for table in ["sites", "posts", "users", "roles", "role_capabilities",
                  "user_role_assignments"] {
        let sql = format!("SELECT count(*)::bigint FROM {table}");
        let (n,): (i64,) = sqlx::query_as(&sql).fetch_one(&mut *tx2).await.unwrap();
        assert_eq!(n, 0, "round {round}: tenant {tb} saw {n} rows of {table} \
                          (RLS leak from tenant {ta})");
    }

    // === Phase 3: attempt cross-tenant INSERT — must fail ===
    let res = sqlx::query(
        "INSERT INTO sites (id, tenant_id, slug, display_name) \
         VALUES ($1, $2, 'x', 'X')"
    ).bind(Uuid::new_v4()).bind(ta)
     .execute(&mut *tx2).await;
    assert!(res.is_err(), "round {round}: WITH CHECK allowed cross-tenant insert");

    drop(tx2); // rollback
}

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **proptest deterministic vs default**: use
     `TestRunner::deterministic()` so failures are reproducible — same
     seed yields same case.
  2. **1000 rounds × 4 transactions each = 4000 transactions.** On a
     warm Docker postgres, < 60 s. On a cold start, allow 90 s timeout
     in test config if you see flakes.
  3. **`glob` crate** is idiomatic and tiny; the dev-dep is justified.
     If `cargo deny` complains, add a Skip rule.
  4. **`SET LOCAL ROLE ax_app` interaction with pool acquisition**:
     `pool.begin()` may pick a connection that has lingering session
     state. `SET LOCAL` is transaction-scoped — resets on COMMIT/
     ROLLBACK. Safe.
  5. **proptest panic on first failure** ends the run. Failure
     message includes the seed → reproduce with
     `PROPTEST_CASES=1 PROPTEST_SEED=<seed> cargo test ...`.
