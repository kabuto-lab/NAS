P1 · `docs/adr/ADR-009-revisions-autosaves.md` (NEW, ~120 LOC)

  Structured: Status, Context, Decision, TLA layers, Consequences,
  References (forward to RFC-007 if any, and PLAN doc for the M3 G5
  impl scope).

  Decisions captured:
   - `revisions` table: `(id, post_id, tenant_id, created_at,
     author_id, snapshot_blocks JSONB, snapshot_title TEXT, summary
     TEXT)`. Snapshot at every save; autosave produces a revision
     with `is_autosave=true` flag.
   - Autosave protocol: client PATCHes with `?autosave=true`; server
     creates revision row BUT does NOT bump `posts.updated_at`. Latest
     manual save still wins for "last edited at" UX.
   - Revert: dedicated endpoint `POST /api/v1/pages/:slug/revisions/:id/revert`
     copies snapshot into post, creates a NEW revision recording the
     revert (provenance preserved).
   - Retention: keep all revisions for 90 days; cleanup via nightly
     job consuming `outbox_search_reindex`-style scheduled-task table
     (separate M3 effort).
   - Permission: viewing revisions = `cms.page.read`; reverting =
     `cms.page.publish` (because revert may change status).

```rust
#[tokio::test]
#[ignore = "needs Docker"]
async fn endpoints_capability_matrix() {
    // ... boot PG + repo + app ...
    let cases: &[(Method, &str, CapsFixture, StatusCode)] = &[
        (Method::GET,    "/api/v1/pages/seeded", NoCaps,         StatusCode::FORBIDDEN),
        (Method::GET,    "/api/v1/pages/seeded", ReadOnly,       StatusCode::OK),
        // ... ~20 rows ...
    ];
    for (method, path, caps, expected) in cases {
        let req = build_req(method.clone(), path, caps_fixture_to_jwt(*caps));
        let resp = app.clone().oneshot(req).await.unwrap();
        assert_eq!(resp.status(), *expected,
                   "case ({method}, {path}, {caps:?}) expected {expected}");
    }
}
```
