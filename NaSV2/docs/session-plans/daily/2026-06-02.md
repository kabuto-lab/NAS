P2 · `crates/domain/src/post.rs` (NEW)

  ```rust
  //! Post aggregate · ENTITY §7 domain model.
  //!
  //! ## State machine (`PostStatus`)
  //!
  //! ```text
  //!   Draft ─────► Scheduled ─────► Published ─────► Archived ─┐
  //!     │                ▲              ▲                       │
  //!     └────────────────┴──────────────┘                       │
  //!              (anywhere → Archived is terminal)              │
  //!                                                             │
  //!   Archived has NO outbound transitions ◄──────────────────  ┘
  //! ```
  //!
  //! Reasons:
  //!   - Draft can fast-track straight to Published or be Scheduled
  //!   - Scheduled is a future-publish placeholder; on time-trigger
  //!     it transitions to Published (callers handle the timer)
  //!   - Published can be Archived (soft delete)
  //!   - Archived is terminal — un-archiving needs a deliberate
  //!     workflow not modelled in this aggregate (a Restore command
  //!     would create a new Post).

  use chrono::{DateTime, Utc};
  use nas2_common::{AppError, PostId, SiteId, TenantId};
  use serde::{Deserialize, Serialize};

  use crate::block::Block;
  use crate::site::validate_slug;

  #[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
  pub struct Post {
      pub id: PostId,
      pub site_id: SiteId,
      pub tenant_id: TenantId,
      pub slug: PostSlug,
      pub title: String,
      pub status: PostStatus,
      /// Set ⇔ `status == Published || status == Archived`. Enforced
      /// by `transition_to`.
      pub published_at: Option<DateTime<Utc>>,
      pub blocks: Vec<Block>,
      pub custom_type: Option<CustomPostType>,
  }

  impl Post {
      /// Apply a status transition. Returns an `AppError::Conflict`
      /// if the transition is forbidden by the FSM.
      pub fn transition_to(&mut self, target: PostStatus, now: DateTime<Utc>)
          -> Result<(), AppError>
      {
          if !self.status.can_transition_to(target) {
              return Err(AppError::Conflict(format!(
                  "post {id} cannot transition {from:?} → {target:?}",
                  id = self.id, from = self.status
              )));
          }
          // published_at invariant
          if matches!(target, PostStatus::Published) && self.published_at.is_none() {
              self.published_at = Some(now);
          }
          self.status = target;
          Ok(())
      }
  }

  #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize)]
  #[serde(rename_all = "snake_case")]
  pub enum PostStatus { Draft, Scheduled, Published, Archived }

  impl PostStatus {
      #[must_use]
      pub const fn can_transition_to(self, target: Self) -> bool {
          use PostStatus::{Archived, Draft, Published, Scheduled};
          matches!((self, target),
              (Draft, Scheduled) | (Draft, Published) | (Draft, Archived) |
              (Scheduled, Published) | (Scheduled, Draft) | (Scheduled, Archived) |
              (Published, Archived)
              // Archived → * forbidden
          )
      }
  }

  /// Per-site unique post slug. Same syntax rules as `SiteSlug`.
  #[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash)]
  #[serde(transparent)]
  pub struct PostSlug(String);

  impl PostSlug {
      pub fn try_new(raw: &str) -> Result<Self, AppError> {
          validate_slug(raw, 3, 80)  // posts allow slightly longer slugs
              .map(|()| Self(raw.to_owned()))
              .map_err(AppError::Validation)
      }

      #[must_use]
      pub fn as_str(&self) -> &str { &self.0 }
  }

  /// Placeholder for extension-defined post types (e.g. `event`,
  /// `case-study`). No validation today; the extension API (month 2+)
  /// will lock the registry.
  #[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq, Hash)]
  #[serde(transparent)]
  pub struct CustomPostType(pub String);
  ```

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **Pattern matching in `can_transition_to` is `const fn`.**
     `matches!` works in const context as of Rust 1.46. OK.
  2. **`transition_to` mutates Self.** Aggregate-style direct
     mutation is correct here — Posts are exclusively owned at the
     boundary of a use case. If you find yourself wanting `Arc<Mutex>`,
     refactor.
  3. **published_at invariant**: only set on Draft→Published or
     Scheduled→Published, NOT on Archived→Published (forbidden) or
     Published→Archived (transition_to keeps the existing value).
     Verify all 4 cases in tests.
  4. **`CustomPostType` validation absent today** — that's deliberate.
     The Extension API (month 2+) will hold the canonical registry of
     valid type names.
  5. **Post slug uniqueness** is NOT enforced here — that's an
     infrastructure (DB unique index) + repo-layer concern. Domain
     value object only enforces *syntax*.
