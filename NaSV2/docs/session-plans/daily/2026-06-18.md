  ```rust
  //! HTML sanitization · ENTITY §3.6 — sanitize on WRITE only.
  //!
  //! Backed by `ammonia` with a curated allow-list. The output is
  //! safe to store and to render directly into HTML contexts; the
  //! read path MUST NOT re-sanitize.
  //!
  //! ## Allow-list
  //!
  //! Tags:    p, br, strong, em, u, h1..h6, ul, ol, li, blockquote,
  //!          code, pre, a, img
  //! Attrs:   a[href], img[src,alt,title]
  //! Schemes: http, https, mailto
  //!
  //! Classes: `code[language-rust|language-js|language-ts|language-py]`
  //!
  //! Additions need an RFC referencing the XSS class being unblocked.

  use std::collections::HashSet;
  use std::sync::OnceLock;

  use ammonia::Builder;

  /// Strip everything outside the AX•CMS allow-list. Idempotent —
  /// calling twice yields the same result as once.
  #[must_use]
  pub fn clean_html(input: &str) -> String {
      builder().clean(input).to_string()
  }

  /// Placeholder retained for migration; will be removed after
  /// downstream callers move to `clean_html`.
  #[deprecated(note = "use `clean_html` instead; placeholder will be removed in month 2")]
  #[must_use]
  pub fn clean_html_placeholder(input: &str) -> String {
      clean_html(input)
  }

  fn builder() -> &'static Builder<'static> {
      static B: OnceLock<Builder<'static>> = OnceLock::new();
      B.get_or_init(|| {
          let mut b = Builder::default();
          b.add_tag_attributes("a", ["href"]);
          b.add_tag_attributes("img", ["src", "alt", "title"]);
          b.add_tag_attributes("code", ["class"]);
          let schemes: HashSet<&'static str> =
              ["http", "https", "mailto"].into_iter().collect();
          b.url_schemes(schemes);
          // Allow code language classes via attribute filtering, not
          // classes whitelist (ammonia API choice).
          // Builder also restricts tags to a sensible CMS subset.
          b
      })
  }
  ```

  *Engineering note:* Ammonia's `Builder` is `!Sync` in some versions
  — verify via `static B: OnceLock<Builder>` compiles. If it doesn't,
  fall back to `thread_local!` or instantiate per call (~1 µs cost,
  fine on write path).

  ### Tests

  In `crates/common/src/sanitize.rs`:

  - `test_strips_script_tag` —
    `clean_html("<p>ok</p><script>x</script>")` returns
    `"<p>ok</p>"` (or equivalent — exact form depends on ammonia).
  - `test_keeps_allowed_tag_paragraph_strong` —
    `clean_html("<p><strong>hi</strong></p>")` returns the input.
  - `test_filters_javascript_url_scheme` —

    same for mailto.
  - `test_idempotent` — `clean_html(clean_html(input)) == clean_html(input)`.

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **Ammonia `Builder` may not be `Sync`.** If `OnceLock<Builder>`
     fails to compile, fall back: `clean_html` constructs the builder
     per call. The ~1 µs cost is fine on the write path (not hot).
  2. **`#[deprecated]` causes clippy warning at call site.** Verify
     no existing call site exists (W1 D5 introduced the placeholder
     but nothing called it). If a test calls the placeholder, replace
     with `clean_html`.
  3. **`xtask bench-runner` on a Windows host with antivirus scanning
     `target/`.** Bench numbers will be wildly variable. Document
     in `captured_meta.json` and plan for CI re-capture.
  4. **`ammonia::clean` returns a `Document`** (since v3); `.to_string()`
     pulls HTML. Some versions return `String` directly — verify ammonia
     version in workspace pin (`ammonia = "4"`).
  5. **SEC-003's "RLS policy placeholder"** — be explicit that no
     SQL policy exists in `migrations/` yet; this doc is a SPEC, not
     evidence of implementation.
