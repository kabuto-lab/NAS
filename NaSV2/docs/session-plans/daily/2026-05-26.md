        - Run `git log --format=%B <range>`
        - Для каждого commit message искать regex
          `\b(RFC|ADR|PLAN|VAL)-\d{3,4}\b`

            patterns в commit message: `^(typo|chore: fmt|chore: deps?|comment:|docs?: typo)`

        - Иначе → stderr с commit SHA + первая строка + missing-refs
          message; exit 1.

        test_accepts_trivial_typo_commit
