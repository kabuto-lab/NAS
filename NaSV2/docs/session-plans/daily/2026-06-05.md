P1 · `crates/application/src/ports/post_repository.rs` (NEW)

  ```rust
  //! Persistence port for `Post` aggregates · ENTITY §2 (hex layer 2).
  //!
  //! Adapters implement this trait in `crates/infrastructure`
  //! (e.g. `PgPostRepository`). Use cases generic over `R: PostRepository`
  //! (static dispatch, §8.3) OR via `Arc<dyn PostRepository>`
  //! (presentation AppState convenience).
  //!
  //! ## TLA layers
  //!
  //! - **L1 Correctness** — every method requires `&TenantContext`
  //!   indirectly via the `(tenant, site)` ID pair; RLS enforcement
  //!   is at the adapter layer (set_config + transaction).
  //! - **L2 Performance** — `list_published` returns `Page<Post>` in
  //!   one DB roundtrip; no N+1 by contract.
  //! - **L3 Scalability** — repo is stateless; clones share the
  //!   underlying pool (Arc internally).
  //! - **L4 Operability** — adapter implementations MUST instrument
  //!   each method with `tracing::instrument` carrying tenant_id.

  use async_trait::async_trait;
  use nas2_common::{AppError, Page, PostId, SiteId, TenantId};
  use nas2_domain::{Post, PostSlug};

  #[cfg_attr(test, mockall::automock)]
  #[async_trait]
  pub trait PostRepository: Send + Sync {
      async fn find_by_slug(
          &self,
          tenant: TenantId,
          site: SiteId,
          slug: &PostSlug,
      ) -> Result<Option<Post>, AppError>;

      async fn find_by_id(
          &self,
          tenant: TenantId,
          id: PostId,
      ) -> Result<Option<Post>, AppError>;

      async fn list_published(
          &self,
          tenant: TenantId,
          site: SiteId,
          page: u32,
          per_page: u32,
      ) -> Result<Page<Post>, AppError>;

      async fn insert(&self, post: &Post) -> Result<(), AppError>;

      async fn update(&self, post: &Post) -> Result<(), AppError>;
  }

  #[cfg(test)]
  mod tests {
      use super::*;

      // Compile-time assertion: trait is dyn-safe so AppState can
      // store `Arc<dyn PostRepository>`.
      #[allow(dead_code)]
      fn _assert_object_safe(_: &dyn PostRepository) {}
  }
  ```

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **`async_trait` generates `Pin<Box<dyn Future>>`** — that's the
     async cost we accept for dyn-safety. Native async fn in traits
     (Rust 1.75+) is dyn-incompatible without `#[trait_variant]`;
     defer until ecosystem catches up.
  2. **`mockall::automock` requires the trait be `#[cfg(test)]`-only
     wrapping or `automock` invoked under `#[cfg_attr(test, ...)]`.**
     We chose the cfg_attr form so the mock type exists only in
     test builds — keeps production binary small.
  3. **Mockall + async_trait** — works fine; the smoke test verifies.
     If you see "the trait `MockPostRepository` is not implemented",
     check that `Box::pin(async { ... })` wraps the body of the
     `returning` closure.
  4. **`Send + Sync` bound** is necessary because AppState shares
     repo across tokio worker threads. dyn-safety is preserved.
  5. **Don't add `#[async_trait]` on the `MockPostRepository` impl
     side** — mockall handles that internally.
