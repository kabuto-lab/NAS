P1 · `EditorState` reorder helpers

  In `editor/canvas.rs`:

```rust
impl EditorState {
    /// Move block at `from` to position `to`. Out-of-bounds → no-op.
    pub fn move_block(&self, from: usize, to: usize) {
        self.blocks.update(|blocks| {
            if from >= blocks.len() || to >= blocks.len() || from == to { return; }
            let b = blocks.remove(from);
            blocks.insert(to, b);
        });
    }

    pub fn move_up(&self, i: usize)   { if i > 0 { self.move_block(i, i - 1); } }
    pub fn move_down(&self, i: usize) {
        let len = self.blocks.with(Vec::len);
        if i + 1 < len { self.move_block(i, i + 1); }
    }
}
```

P3 · Server-side fallback: `POST /admin/posts/:slug/blocks/reorder`

  For non-JS / no-hydration fallback paths.

  `crates/presentation/src/admin/posts.rs`:

```rust
#[derive(Debug, serde::Deserialize)]
pub struct ReorderForm {
    from: usize,
    to: usize,
    csrf: String,
}

// caps.require(cms.page.draft)
pub async fn post_reorder_action(
    _: RequireCaps<CmsPageDraft>,
    State(state): State<AppState>,
    Extension(tctx): Extension<TenantContext>,
    Path(slug_raw): Path<String>,
    Form(form): Form<ReorderForm>,
) -> Result<Response, AppError> {
    let slug = PostSlug::try_new(&slug_raw)?;
    let mut post = state.post_repo.find_by_slug(tctx.tenant_id, tctx.site_id, &slug).await?
        .ok_or_else(|| AppError::NotFound(format!("post {slug_raw}")))?;
    if form.from >= post.blocks.len() || form.to >= post.blocks.len() {
        return Err(AppError::Validation("out-of-bounds index".into()));
    }
    let b = post.blocks.remove(form.from);
    post.blocks.insert(form.to, b);
    state.post_repo.update(&post).await?;
    Ok(Redirect::to(&format!("/admin/posts/{slug_raw}/edit")).into_response())
}
```

  Wire route: `.route("/admin/posts/:slug/blocks/reorder", post(post_reorder_action))`.

  Add `draggable=true` + `on:dragstart` / `on:dragover` / `on:drop`

```rust
let drag_source = RwSignal::new(None::<usize>);
provide_context(drag_source);

// In BlockNode:
let on_dragstart = move |ev: web_sys::DragEvent| {
    drag_source.set(Some(index));
    if let Some(dt) = ev.data_transfer() {
        dt.set_effect_allowed("move");
    }
};
let on_dragover = move |ev: web_sys::DragEvent| { ev.prevent_default(); };
let on_drop = move |ev: web_sys::DragEvent| {
    ev.prevent_default();
    if let Some(from) = drag_source.get() {
        state.move_block(from, index);
    }
    drag_source.set(None);
};

view! {
    <article class="block-node"
             draggable=true
             on:dragstart=on_dragstart
             on:dragover=on_dragover
             on:drop=on_drop>
        // ...
    </article>
}
```

PERFORMANCE / SECURITY / PITFALLS
═════════════════════════════════════════════════════════════════════

  - Reorder fallback handler runs `find_by_slug` + `update` — TWO
    round-trips. Acceptable for explicit user action; optimisation

    reorder. Verify no accessibility regression (blocks listed in
    Tab cycle).
  - `prevent_default` on dragover REQUIRED for drop to fire — common
    DnD pitfall.
