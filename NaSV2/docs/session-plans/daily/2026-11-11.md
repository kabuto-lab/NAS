P1 · `crates/presentation/src/admin/breadcrumb.rs` (NEW)

```rust
//! Typed breadcrumb chain · M7 W1 D3.

use leptos::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Crumb {
    pub label: String,
    /// None == terminal (current page; rendered as plain text).
    pub href: Option<String>,
}

impl Crumb {
    #[must_use]
    pub fn linked(label: impl Into<String>, href: impl Into<String>) -> Self {
        Self { label: label.into(), href: Some(href.into()) }
    }
    #[must_use]
    pub fn terminal(label: impl Into<String>) -> Self {
        Self { label: label.into(), href: None }
    }
}

#[derive(Clone, Debug, Default)]
pub struct BreadcrumbChain(pub Vec<Crumb>);

impl BreadcrumbChain {
    #[must_use]
    pub fn root() -> Self {
        Self(vec![Crumb::linked("Admin", "/admin")])
    }
    pub fn push(mut self, c: Crumb) -> Self {
        self.0.push(c);
        self
    }
}

#[component]
pub fn Breadcrumbs(chain: BreadcrumbChain) -> impl IntoView {
    let items = chain.0.into_iter().enumerate().collect::<Vec<_>>();
    let total = items.len();
    view! {
        <nav class="breadcrumbs" aria-label="breadcrumb">
            <ol>
                {items.into_iter().map(|(i, crumb)| {
                    let is_last = i == total - 1;
                    let separator = (i > 0).then(|| view! {
                        <span class="sep" aria-hidden="true">"›"</span>
                    });
                    view! {
                        <li>
                            {separator}
                            {match crumb.href {
                                Some(href) if !is_last => view! {
                                    <a href=href>{crumb.label}</a>
                                }.into_any(),
                                _ => view! { <span aria-current="page">{crumb.label}</span> }.into_any(),
                            }}
                        </li>
                    }
                }).collect_view()}
            </ol>
        </nav>
    }
}
```

P2 · Decision: where do crumbs live?

  Options:
   (a) `AdminContext.crumbs: BreadcrumbChain` — set by handler before
       SSR.
   (b) `AdminLayout` accepts `crumbs` as a separate prop.

  Pick (b): keeps `AdminContext` request-immutable + crumbs are
  truly per-page. `AdminLayout` already accepts `title` — adding
  `crumbs` is symmetric.

  Update `admin/layout.rs`:

```rust
#[component]
pub fn AdminLayout(
    ctx: AdminContext,
    title: &'static str,
    #[prop(optional)] crumbs: Option<BreadcrumbChain>,
    children: Children,
) -> impl IntoView {
    provide_meta_context();
    provide_context(ctx);
    let crumbs = crumbs.unwrap_or_else(BreadcrumbChain::root);
    view! {
        <Title text=format!("{title} · AX•CMS Admin")/>
        <Stylesheet href="/admin/static/admin.css"/>
        <div class="admin-root">
            <AdminNav/>
            <main class="admin-main">
                <Breadcrumbs chain=crumbs/>
                <h1 class="page-title">{title}</h1>
                {children()}
            </main>
        </div>
    }
}
```

```rust
#![allow(clippy::expect_used, clippy::unwrap_used)]

use leptos::prelude::*;
use nas2_presentation::admin::{BreadcrumbChain, Breadcrumbs, Crumb};

fn render(chain: BreadcrumbChain) -> String {
    leptos::ssr::render_to_string(move || view! { <Breadcrumbs chain/> })
        .into_owned()
}

#[tokio::test]
async fn empty_chain_renders_empty_ol() {
    let html = render(BreadcrumbChain(vec![]));
    assert!(html.contains("<ol>"));
    assert!(!html.contains("<li>"));
}

#[tokio::test]
async fn single_level_renders_no_separator() {
    let html = render(BreadcrumbChain::root());
    assert!(html.contains("<a href=\"/admin\">Admin</a>"));
    assert!(!html.contains("›"));
}

#[tokio::test]
async fn nested_renders_separator_and_terminal_no_link() {
    let chain = BreadcrumbChain::root()
        .push(Crumb::linked("Posts", "/admin/posts"))
        .push(Crumb::terminal("Edit"));
    let html = render(chain);
    assert!(html.contains("Admin"));
    assert!(html.contains("Posts"));
    assert!(html.contains(r#"<span aria-current="page">Edit</span>"#));
    assert_eq!(html.matches("›").count(), 2);
}
```

PERFORMANCE / SECURITY CONSIDERATIONS
═════════════════════════════════════════════════════════════════════

  - Crumb labels appear in HTML — if a label comes from user input
    (e.g. post slug), Leptos auto-escapes via the `view!` macro. NO
    `dangerously_set_inner_html` calls anywhere.
  - Crumb chain is per-request — no global state, no leak between
    tenants.
  - Render cost: O(n) for n crumbs, n ≤ 5 in practice. Negligible.
  - Breadcrumb URLs use `<a href>` — relative paths only; no
    cross-origin risk.

═════════════════════════════════════════════════════════════════════
COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **`view!` macro and `.into_any()`** — required when match arms
     return different concrete types (Leptos 0.7 quirk). Verify
     compile.
  2. **Slug in crumb labels** could contain HTML-unsafe chars in
     theory — `PostSlug::try_new` (M1 W2 D2) rejects them, so by the
     time a slug reaches a crumb it's `[a-z0-9-]+`. Defence-in-depth:
     never trust; let Leptos auto-escape.
  3. **`AdminLayout` prop order** — `crumbs` is optional with
     `#[prop(optional)]`; ordering matters in view! macro callers.
     Use named-prop syntax everywhere: `crumbs=chain` not positional.
  4. **CSS class names** must be unique to admin scope — prefix all
     with `.breadcrumbs` etc. to avoid bleed into future public
     theme CSS.
  5. **Tests use `tokio::test`** even though render_to_string is
     sync — keeps the harness uniform with future async tests.
