P1 · Promote `CapabilitySet::cache_key_hash`

  Edit `crates/domain/src/capability.rs`. Replace the existing impl
  with the seeded form:

  ```rust
  /// Non-cryptographic, per-process-stable hash composed with an
  /// optional `seed`. Useful for cache key composition (§3.9.1).
  ///
  /// **Caveats:**
  ///   - Within a single process invocation, equal sets yield equal
  ///     hashes regardless of insertion order (BTreeSet is ordered).
  ///   - Across processes or Rust versions, values may differ —
  ///     `DefaultHasher` is intentionally unstable.
  ///   - For cross-process stability (e.g. an L2 cache shared with
  ///     a non-Rust service), switch to `xxh3_64` via the
  ///     `xxhash-rust` crate. Adding that dep is a separate ADR.
  ///
  /// The `seed` argument lets callers mix in additional context
  /// (e.g. tenant_id hash) without rebuilding the set.
  #[must_use]
  pub fn cache_key_hash(&self, seed: u64) -> u64 {
      use std::hash::{Hash, Hasher};
      let mut h = std::collections::hash_map::DefaultHasher::new();
      seed.hash(&mut h);
      for c in &self.0 {
          c.hash(&mut h);
      }
      h.finish()
  }
  ```

  Existing call sites: none yet (the helper was unused). The seeded
  form is forward-compatible.
