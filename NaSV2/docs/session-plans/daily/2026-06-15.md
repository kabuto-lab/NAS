P1 · Refactor caps extraction for test injection

  The cleanest way to inject caps without re-architecting AppState is
  a thread-local override under `#[cfg(test)]`. Alternative considered:
  pass caps through AppState (production complexity). Rejected: the
  override is test-only and ephemeral.

  Edit `crates/presentation/src/caps.rs`:

  ```rust
  use std::cell::RefCell;

  use nas2_domain::{Capability, CapabilitySet};

  thread_local! {
      #[cfg(test)]
      static CAPS_OVERRIDE: RefCell<Option<CapabilitySet>> = const { RefCell::new(None) };
  }

  /// Default extractor — returns the stub set today; in month 2 this
  /// becomes JWT-derived. The marker comment is required.
  ///
  /// caps.require(cms.page.read)
  #[must_use]
  pub fn extract_caps_for_today() -> CapabilitySet {
      #[cfg(test)]
      {
          let from_thread = CAPS_OVERRIDE.with(|c| c.borrow().clone());
          if let Some(caps) = from_thread {
              return caps;
          }
      }
      CapabilitySet::from_iter([Capability::CmsPageRead])
  }

  /// Test-only: set the per-thread caps override for the next
  /// `extract_caps_for_today` call(s). Returns a guard that restores
  /// the previous value on drop.
  #[cfg(test)]
  #[must_use]
  pub fn with_caps_for_test(caps: CapabilitySet) -> CapsGuard {
      let prev = CAPS_OVERRIDE.with(|c| c.replace(Some(caps)));
      CapsGuard { prev }
  }

  #[cfg(test)]
  pub struct CapsGuard { prev: Option<CapabilitySet> }

  #[cfg(test)]
  impl Drop for CapsGuard {
      fn drop(&mut self) {
          CAPS_OVERRIDE.with(|c| *c.borrow_mut() = self.prev.take());
      }
  }
  ```

  Why thread-local: integration tests use `#[tokio::test]` which by
  default runs on the current thread (`flavor = "current_thread"` —
  axum's `oneshot` doesn't switch threads). `thread_local!` works
  cleanly. If a future test uses multi-thread runtime, switch to
  `tokio::task_local!` or pass via Extension.

  Old `extract_caps_for_test` removed (replaced by `with_caps_for_test`
  guard pattern — RAII makes leaks impossible).

P2 · Extend `crates/presentation/tests/get_page_by_slug.rs`

  Add three tests:

  ```rust
  // (Keep existing returns_200_for_published_page — no changes.)

  #[tokio::test]
  async fn returns_403_when_caps_missing() {
      use nas2_domain::CapabilitySet;
      use nas2_presentation::caps::with_caps_for_test;

      let host = "example.com";
      let repo = MockRepo::new(); // no expectations → never reached
      let app = build_router(build_state(host, Arc::new(repo)));

      // Hold the guard for the lifetime of the request.
      let _guard = with_caps_for_test(CapabilitySet::new());
      let req = Request::builder()
          .uri("/api/v1/pages/hello")
          .header(header::HOST, host)
          .body(Body::empty()).unwrap();
      let resp = app.oneshot(req).await.unwrap();

      assert_eq!(resp.status(), StatusCode::FORBIDDEN);
      let bytes = axum::body::to_bytes(resp.into_body(), 1024).await.unwrap();
      let v: serde_json::Value = serde_json::from_slice(&bytes).unwrap();
      assert_eq!(v.get("code").and_then(|s| s.as_str()), Some("forbidden"));
      assert!(v.get("message").and_then(|s| s.as_str())
          .unwrap_or("").contains("cms.page.read"));
  }

  #[tokio::test]
  async fn returns_404_when_slug_not_found() {
      let host = "example.com";
      let mut repo = MockRepo::new();
      repo.expect_find_by_slug()
          .returning(|_, _, _| Box::pin(async { Ok(None) }));
      let app = build_router(build_state(host, Arc::new(repo)));

      let req = Request::builder()
          .uri("/api/v1/pages/missing")
          .header(header::HOST, host)
          .body(Body::empty()).unwrap();
      let resp = app.oneshot(req).await.unwrap();

      assert_eq!(resp.status(), StatusCode::NOT_FOUND);
      let bytes = axum::body::to_bytes(resp.into_body(), 1024).await.unwrap();
      let v: serde_json::Value = serde_json::from_slice(&bytes).unwrap();
      assert_eq!(v.get("code").and_then(|s| s.as_str()), Some("not_found"));
  }

  #[tokio::test]
  async fn returns_400_when_slug_invalid_chars() {
      let host = "example.com";
      let repo = MockRepo::new(); // never reached — slug validation
                                  // happens before repo call
      let app = build_router(build_state(host, Arc::new(repo)));

      // Slug "BadSlug!" fails PostSlug::try_new (uppercase, '!').
      // Note: axum's Path extractor accepts arbitrary chars; the
      // validation happens inside the handler.
      // Use percent-encoding for '!' so the router sees it.
      let req = Request::builder()
          .uri("/api/v1/pages/BadSlug%21")
          .header(header::HOST, host)
          .body(Body::empty()).unwrap();
      let resp = app.oneshot(req).await.unwrap();

      assert_eq!(resp.status(), StatusCode::BAD_REQUEST);
      let bytes = axum::body::to_bytes(resp.into_body(), 1024).await.unwrap();
      let v: serde_json::Value = serde_json::from_slice(&bytes).unwrap();
      assert_eq!(v.get("code").and_then(|s| s.as_str()), Some("validation_failed"));
  }
  ```

COMMON PITFALLS
═════════════════════════════════════════════════════════════════════

  1. **`#[tokio::test]` defaults to current_thread runtime in 2024+.**
     Thread-local override works. If a future test uses
     `#[tokio::test(flavor = "multi_thread")]`, the override may not
     propagate. Switch to `tokio::task_local!` then.
  2. **`with_caps_for_test` guard MUST be held across the await.**
     `let _guard = ...; app.oneshot(req).await;` is correct.
     `let _ = with_caps_for_test(...);` (anonymous binding) drops
     the guard immediately — DON'T do that. The `unused_variables`
     lint will flag if you typo.
  3. **`PostSlug::try_new` rejects uppercase letters AND `'!'`.**
     The percent-encoded `%21` is decoded by axum's router before
     reaching the handler — verify with a debug print if unsure.
  4. **Body collection cap of 1024.** Plenty for error envelopes;
     larger for happy-path test (16 KiB). Don't standardize on one
     value — pick per test.
  5. **`assert_eq!(StatusCode::FORBIDDEN, ...)` vs `assert_eq!(403, ...)`.**
     Always use the named constant — clearer and IDE-navigable.
